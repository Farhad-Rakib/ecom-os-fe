# Index Standards

Regenerate `slipway/standards/index.yml` by scanning
`slipway/standards/*.md` directly — for when standards files were
added or edited by hand (or by `/discover-standards`) rather than
through `project-install.sh`, which generates its own index as part of
installing a profile.

## Process

### Step 1 — Scan

List every `*.md` file directly under `slipway/standards/` (not
`index.yml` itself).

### Step 2 — Preserve provenance where known

Read the existing `index.yml` if present. For any file it already
lists, keep its `from_profile` value. For a new file with no prior
entry, set `from_profile: "manual"` — it didn't come from a profile
install.

### Step 3 — Write a one-line description per file

For each file, read its first `#` heading or first paragraph and
summarize its purpose in under 15 words — this is what makes the
index actually useful for a quick scan, not just a file listing.

### Step 4 — Write `index.yml`

```yaml
# Generated by /index-standards — do not hand-edit, run the command again instead.
files:
  - {file: "tech-stack.md", from_profile: "default", description: "..."}
  - {file: "coding-standards.md", from_profile: "default", description: "..."}
```

### Step 5 — Confirm

```
✓ slipway/standards/index.yml regenerated: <N> file(s) indexed.
```

## Rules

- Never remove a file from the index that still exists on disk, and
  never list one that doesn't — the index must exactly match what's
  actually in `slipway/standards/`.
- Don't guess at `from_profile` for a file that's genuinely new —
  `"manual"` is the honest answer, not a guess at which profile it
  resembles.
